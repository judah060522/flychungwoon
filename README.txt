Fly Cheongwoon 체크인 대기 시뮬레이터

사용 방법
1. 이 폴더의 index.html을 더블클릭하면 됩니다.
2. Chrome, Edge 등 브라우저에서 실행됩니다.
3. 실제 이메일은 전송하지 않습니다.
4. 입력한 이메일은 시뮬레이션용 데이터로만 사용됩니다.

기능
- 대기 등록
- 이메일/전화번호 입력
- 인원 입력
- 실제 순번 계산
- 등록 후 10분이 지나면 자동으로 대기열에서 제거
- 실시간 대기팀 수
- 팀당 3분 예상 대기시간
- 한국어/중국어/영어/일본어
- 등록 완료 후 5초 뒤 메인 화면 복귀
- 브라우저 localStorage를 이용한 시뮬레이션

주의
이 버전은 서버가 없는 시뮬레이터입니다. 다른 컴퓨터/휴대폰에서 등록한 사람이 서로 공유되는 시스템은 아닙니다.
